사이언스샵 / 심박계 사용 매뉴얼

연결하고 설정한 뒤 측정하기

승재쌤이 직접 캡처한 실제 화면을 보며 따라 해요.

01 심박 센서 연결

① 화면 오른쪽 위의 ‘연결’을 누릅니다.
② 목록에서 우리 모둠의 심박 센서를 선택합니다.
③ 선택한 센서를 확인하고 창 안의 ‘연결’을 누릅니다.

캡처의 ‘심박계-103’은 예시입니다. 실제 사용하는 센서의 번호를 확인하세요.

02 실험 설정

상단의 ‘실험설정’을 누릅니다.
데이터 수집 방법: 자동수집
차트 종류: 선차트

수집 간격과 실험시간은 실험 특성에 따라 모둠별로 판단해 설정한 뒤 ‘확인’ 버튼을 누릅니다.

03 측정 시작과 종료

‘시작’을 눌러 측정합니다.
데이터 수집이 끝나면 ‘종료’를 누릅니다.

Hz = 1초당 데이터 수집 횟수
3 Hz = 1초에 3회 수집
심박수(회/분)와는 달라요.

그래프를 확인하고 측정 오류 정리하기

승재쌤이 직접 캡처한 실제 화면을 보며 따라 해요.

04 그래프를 한 화면에 맞추기

그래프가 잘리거나 한 화면에 보이지 않으면 왼쪽 도구 모음의 네 방향 화살표 아이콘을 누릅니다.

캡처의 빨간 네모 위치를 확인하세요.

05 잘못 측정된 구간 정리

① 먼저 원본 데이터를 저장해 둡니다.
② 왼쪽의 지우개 모양 아이콘을 누릅니다.
③ 잘못 측정된 구간을 드래그해 선택합니다.
④ 선택 범위를 확인하고 ‘삭제’를 누릅니다.

삭제한 데이터는 복구할 수 없어요. 센서가 빠지는 등 측정 오류가 확인된 구간만 제외하고, 이유를 기록해요.
